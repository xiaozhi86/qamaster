# 27、安全测试维度（OWASP 式）

> 当需求涉及 P0 安全风险或用户/资金/权限数据时执行。安全用例测试类型填"安全"，测试维度填"安全验证"。

## 水平越权
* A 角色访问 B 角色同层级数据（如用户A查用户B的订单）
* 越权查看 / 越权修改 / 越权删除

## 垂直越权
* 普通用户调用管理员接口
* 低权限角色执行高权限操作

## 身份认证
* 未登录访问受保护资源
* Token 伪造 / 篡改 / 过期后重放
* 会话固定攻击

## 注入
* SQL 注入（输入框、查询条件、排序字段）
* 命令注入
* XSS（存储型 / 反射型 / DOM型）
* 模板注入 / XPath 注入

## 服务端请求伪造与文件
* SSRF（URL 参数触发服务端请求内网）
* 任意文件上传 / 文件类型绕过
* 路径遍历

## 跨站请求与重定向
* CSRF（关键操作无防 token）
* 开放重定向

## 敏感信息泄露
* 响应体返回敏感字段（密码、身份证、Token）
* 错误信息泄露堆栈 / SQL
* 日志泄露敏感信息
* URL 参数携带敏感数据

## 业务安全
* 验证码绕过 / 暴力破解
* 接口幂等缺失导致的重复发货 / 重复提现
* 竞态条件（并发领券、并发扣库存）
* 负数 / 超限金额导致资金反向操作

# 29、性能 / 兼容性 / 本地化测试方法

> 当测试类型涉及"兼容性""可靠性"或需求明确要求时执行。本节为方法指引，非每次必做。

## 性能与可靠性
* 负载测试：阶梯加压至预期峰值 QPS，验证响应时间与错误率阈值
* 压力测试：超过峰值至崩溃点，验证降级与熔断
* 稳定性测试：长时间持续负载，验证内存泄漏与连接池
* 重试 / 补偿 / 回滚验证：见 SKILL.md 0.6 隐含风险
* 超时与降级：接口超时阈值验证、降级路径可观测

## 兼容性
* 浏览器兼容矩阵（Chrome / Edge / Safari / Firefox × 主流版本）
* 设备兼容（PC / 移动端 / 平板）
* 分辨率兼容
* 接口版本兼容（v1/v2 并存、向后兼容）

## 本地化（i18n）
* 多语言文案完整性（无漏译、无截断）
* 日期 / 货币 / 时区格式
* 字符编码（UTF-8 全链路）
* RTL 布局（如适用）
